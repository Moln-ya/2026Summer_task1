# V2 Dataset
## Task
Object detection.
## Classes
0. keyboard
1. phone
2. nongfu_spring
## Dataset evolution
The previous V1 dataset contained:
- keyboard
- laptop
- phone
For V2:
- keyboard was retained
- phone was retained
- laptop was removed
- Nongfu Spring water bottle was added
## Annotation
Annotations were imported into Roboflow and manually reviewed/corrected before training.
The reviewed Roboflow batch used for this V2 baseline contains 596 images.
## Notes
The raw image dataset is not stored in Git because of its size.
Only dataset metadata and experiment records are version-controlled.
